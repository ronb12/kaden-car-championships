# Racing music (CC0 / commercial-safe)

Drop licensed tracks into `ios/KadenRacing/Resources/Audio/` using these names:

| File | Folder | Used for |
|------|--------|----------|
| `menu_theme.m4a` | `Music/Menu/` | Main menu |
| `garage_theme.m4a` | `Music/Menu/` | Garage / car select |
| `race_intensity.m4a` | `Music/Race/` | In-race playlist (shuffled with race_fever / highway / neon / hot) |
| `countdown.m4a` | `Music/Race/` | Start countdown |
| `victory.m4a` | `Music/Victory/` | Finish screen |

Formats: `.m4a`, `.mp3`, or `.wav`. If a file is missing, the app uses **procedural synthwave** (no copyright).

## Suggested sources

- [Pixabay Music](https://pixabay.com/music/) — filter “free for commercial use”
- [OpenGameArt](https://opengameart.org/) — CC0 / CC-BY (attribute in `AUDIO_ATTRIBUTION.txt`)
- [FreeSound](https://freesound.org/) — SFX only; check license per clip

Add attribution lines to `ios/KadenRacing/Resources/Audio/AUDIO_ATTRIBUTION.txt` for every bundled track.
