# Kaden Racing — Asset Pipeline

Modular environment assets for iOS (SceneKit). Runtime loads from the app bundle copy of `public/models/`.

## Layout

| Folder | Contents |
|--------|----------|
| `Environment/` | Track profiles, biome rules, decor density |
| `Roads/` | Kenney City Kit Roads (`public/models/city/roads/`) |
| `Buildings/` | Commercial + suburban kits |
| `Nature/` | Trees, rocks, terrain textures |
| `Props/` | Lights, barriers, signs, billboards |
| `Lighting/` | IBL gradients, fog presets (procedural) |
| `Skyboxes/` | Sky dome gradients (procedural) |
| `Tracks/` | Authored circuit definitions (`CoastalCityCircuit`) |
| `Materials/` | PBR presets (`EnvironmentMaterialLibrary`) |
| `Vehicles/` | `public/models/cars/` |
| `Effects/` | Particle / skid definitions |
| `Audio/` | `ios/KadenRacing/Resources/Audio/` |
| `UI/` | `ios/KadenRacing/Resources/Assets.xcassets` |
